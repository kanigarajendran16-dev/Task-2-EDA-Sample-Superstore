# Task 2 - Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a Sample Superstore dataset using Python.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## EDA Performed

- Dataset overview
- Data cleaning
- Missing value analysis
- Duplicate removal
- Summary statistics
- Sales distribution
- Profit outlier analysis
- Sales by category
- Profit by category
- Monthly sales trend
- Correlation heatmap

## Key Insights

1. Sales values are mostly concentrated in the lower range.
2. Profit values show variation and some potential outliers.
3. Sales and profit performance varies across categories and months.

## Conclusion

The Exploratory Data Analysis helped identify important patterns,
relationships, variations, and trends in the dataset. The visualizations
provide a clear understanding of sales, profit, categories, monthly trends,
and possible outliers.
